# 模块分工与关键实现

前端没有框架、没有打包器：`app/index.html` 按顺序 `<script>` 引入十几个全局模块，
各自挂一个全局对象（`UI` / `Bank` / `Exam` / `Essay` / `Trans` / `Words` / `Listen` / `Rubric` / `Store` / `AI`）。
改完刷新页面就生效。

## 数据流

```
index.json ──► Bank.loadIndex() ──► 列表页（场次分组）
                 │
                 └─ Bank.get(setId) ──► fetch 单套 JSON ──► Exam / Essay / Trans
```

`file://` 下浏览器禁用 `fetch`，`Bank` 会退回注入 `bank.js` / `listening.js` 打包产物。
网页版首屏不加载这两个文件。

## 各模块

| 文件 | 职责 |
|---|---|
| `js/app.js` | `Store`（localStorage 读写、进度/错题/生词/设置）、通用工具 |
| `js/ui.js` | 首页、场次宫格、套卷列表、阅读专项入口、底部导航 |
| `js/bank.js` | 题库加载与场次分组（真题按年月，原创模拟单独一组） |
| `js/exam.js` | 阅读作答引擎：三种题型的渲染、作答、判分、逐题回顾、原文定位、点词查义 |
| `js/listen.js` | 听力：播放器（录音 / TTS）、交卷判分、原文与解析 |
| `js/essay.js` | 作文：选题目、拍照/相册导入、AI 批改、离线评分、模板库、范文 |
| `js/trans.js` | 翻译：选段落、图片导入、AI 对照批改、离线评分 |
| `js/words.js` | 生词本 / 错题本 |
| `js/me.js` | 我的：AI 配置、考试级别、语音自检、数据导出导入 |
| `js/ai.js` | OpenAI 兼容客户端：流式补全、JSON 容错、各场景提示词 |
| `js/rubric.js` | 离线评分引擎（特征 + 规则） |
| `js/rubric_w.js` | 生成的词表与系数，`rubric.js` 依赖它，必须在它之前加载 |
| `js/offline.js` | 离线评分的门面（作文 / 翻译） |

## 几个关键实现

### 1. 原文定位（解析里的红色引用）

`Exam.bestPara(sec, q)` 用「题干 + 正确选项关键词」去和每段做稀有度加权匹配：
词越罕见权重越高，专有名词额外加权，再叠加一个「题号靠后 → 段落靠后」的先验。
选出来的段落用于两处：解析里的 `src-quote`，以及正文里的段落高亮 + 句子高亮。
两者共用同一套算法，所以能对上。

### 2. 点词查义

`Exam.dictEntry(w)` 先查 `CET_DICT`，查不到再做词形还原（复数 / 三单 / 过去式 / 进行时 / 比较级）。
词条释义按 `v.` `n.` `adj.` 之类的前缀拆成多个义项，界面分「本文意思 / 常用意思」两块：
本文意思用 `ctxSentence` 取所在句，再用简单规则猜词性（看前后词）挑最贴近的义项。

### 3. 吸顶题干卡

阅读页的题干卡 `position: sticky`。手机上最高 46vh，「收起选项」后只剩题干，原文能多显示一倍。
段落匹配与仔细阅读默认只展示第一段 + 题目列表（不带选项），点蓝色题号才展开全文，
避免一进页面就是几屏英文。

### 4. 离线评分

见 README「离线评分是怎么做的」。要点是先把标点粘连规范化，否则整篇缺空格会被算成十几个错误，
把一篇好作文压到 5 分。

### 5. TTS

见 README「语音朗读」。四个坑：手势、GC、cancel 竞态、音色加载时机。

### 6. 平板适配

单套代码 + 媒体查询：

- `720px`：`read-detail` 变两栏（原文 flex:1，题目卡 360px），底部导航限宽 760px
- `1080px`：内容区 1040px，题目卡 420px，原文 18.5px
